## 🚀 開発の始め方

### ステップ1: ドキュメントを読む

1. まず `detailed_specification.md` を読んで、プロジェクト全体を理解する
2. 次に `DEVELOPMENT_GUIDE.md` を読んで、開発環境の準備方法を確認する

### ステップ2: 環境構築

```bash
# モバイルアプリの初期化
npx create-expo-app@latest photo-memory-timeline --template blank-typescript
cd photo-memory-timeline

# 必要なパッケージをインストール（詳細はDEVELOPMENT_GUIDE.mdを参照）
npx expo install expo-media-library expo-location expo-image-picker
# ... その他のパッケージ

# バックエンドの初期化
mkdir backend
cd backend
pnpm init
pnpm add express cors dotenv mysql2 drizzle-orm
# ... その他のパッケージ
```

### ステップ3: Phase 1（MVP）から開発開始

`DEVELOPMENT_GUIDE.md`のPhase 1セクションに従って、以下の機能から実装を開始します：

1. ユーザー認証
2. 写真同期機能
3. 写真一覧表示
4. 月次カレンダーUI

### ステップ4: Claude Code / Cursorで開発

AIコーディングツールに以下のように指示します：

```
「DEVELOPMENT_GUIDE.mdを参照して、Phase 1のユーザー認証機能から実装を開始してください。
backend/src/routes/auth.tsとbackend/src/controllers/authController.tsを作成してください。」
```

## 📝 主要機能

### 1. 写真同期
iPhoneの写真ライブラリから写真を自動同期し、EXIF情報（撮影日時、GPS座標）を抽出します。

### 2. AI分析
OpenAI Vision APIを使用して、写真から以下を自動検出：
- シーン分類（食事、旅行、スポーツなど）
- 物体検出
- 雰囲気分析
- 人物検出

### 3. イベント自動生成
時間的に近い写真を自動的にグルーピングし、イベントとして整理します。各イベントには以下が含まれます：
- 自動生成されたタイトル
- 「いつ・誰と・何を・どこで」のサマリー
- 代表写真

### 4. タイムライン表示
月次カレンダー形式でイベントを表示し、過去の思い出を簡単に振り返れます。

### 5. 人物認識
顔検出と人物グルーピングにより、「誰と」の情報を自動的に抽出します。

### 6. 検索・フィルタリング
日付、人物、場所、イベントタイプで写真を検索できます。

### 7. 共有機能
イベントを他のユーザーと共有できます（共有リンク、QRコード）。
